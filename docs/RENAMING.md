# Aether Cloud → Zyvor Axiom rename map

This source tree is a full product rename, not only a UI label change.

| Old identity | New identity |
|---|---|
| Aether Cloud | Zyvor Axiom |
| `github.com/zyvor/aether-cloud` | `github.com/zyvorai/axiom` |
| `aether-cloud` binary | `zyvor-axiom` |
| `AETHER_*` environment variables | `AXIOM_*` |
| `aether-system` namespace | `axiom-system` |
| `aether.zyvor.dev/*` annotations | `axiom.zyvor.dev/*` |
| managed-by `aether-cloud` | managed-by `zyvor-axiom` |
| browser storage `aether.*` | browser storage `axiom.*` |
| Aether visual orb | Axiom visual core |

No Metal3 workload provider is present in this project.
